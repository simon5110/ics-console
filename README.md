# ICS Console（工业控制台）

一个用 [Avalonia](https://avaloniaui.net/) 开发的**工业控制管理系统**桌面应用，用于集中展示和管理工厂里的设备运行状态、能源耗量、报警信息、设备台账等数据。

> 目前项目处于**演示 / 原型阶段**，页面里的数据（设备状态、报警、能耗等）都是**随机模拟**生成的，尚未接入真实的 PLC、数据库和传感器。

## 功能页面

应用左侧是导航菜单，共 6 个功能页面：

| 页面 | 功能 |
| --- | --- |
| 主页 | 顶部显示 CPU / 内存 / 磁盘利用率卡片（每 3 秒自动刷新），下方是报警信息表格，支持分页与每页条数切换 |
| 可编程控制器 | 串口参数配置（COM 口、波特率等）、多种能源（电、水、天然气等）耗量录入，右侧展示 8 种能源的今日 / 昨日耗量对比柱状图与趋势曲线 |
| 数据库系统 | 左侧"工厂 → 车间 → 工序"树形结构，右侧设备台账表格（支持勾选高亮、搜索），底部是设备全生命周期时间线（采购 → 安装 → 运行 → 保养 → 升级 → 故障 → 报废） |
| 嵌入式系统 | 两个电机控制面板：实时转速曲线（坐标轴量程自适应）、运行模式切换（平稳 / 标准 / 高效 / 狂暴 / 自适应）、转速细调、急停按钮 |
| 操作与文件系统 | 顶部 6 个设备状态卡片（运行 / 停止 / 报警），中部 OEE、能耗、产量 3 个 KPI 面板（带趋势小图），底部设备台账表格 |
| 实时通信系统 | 产量统计面积图、订单完成率环形图、班组技能雷达图（可切换组员）、产线产量对比柱状图（可切换日 / 周 / 月）、区域班组 TOP3 排行 |

窗口顶栏可以折叠 / 展开左侧菜单；左下角会显示当前日期和时间。

## 技术栈

- **.NET 10**（C#）
- **Avalonia 12.1**：跨平台桌面 UI 框架（Windows / Linux / macOS）
- **CommunityToolkit.Mvvm**：MVVM 架构（数据与界面分离）
- **LiveChartsCore**：图表库（柱状图、折线图、环形图、雷达图等）
- **Irihi.Ursa + Semi.Avalonia**：界面控件库与主题样式

## 运行项目

需要安装 [.NET 10 SDK](https://dotnet.microsoft.com/download)。

```bash
# 在项目根目录（含 rockDrill.sln）执行
dotnet run --project rockDrill
```

或者用 Visual Studio / Rider 打开 `rockDrill.sln`，直接运行 `rockDrill` 项目。

## 项目结构

```
rockDrill/
├── rockDrill.sln                  # 解决方案文件
├── rockDrill/                     # 主项目
│   ├── App.axaml            # 应用入口
│   ├── Program.cs
│   ├── ViewModels/          # 各页面的数据逻辑（页面功能主要在这里）
│   ├── Views/               # 各页面的界面文件（.axaml）
│   ├── Converters/          # 界面绑定用的值转换器
│   ├── MyControls/          # 自定义控件（如圆形进度条）
│   └── Assets/              # 图片、图标等资源
```

代码遵循 MVVM 模式：`Views/` 只负责界面显示，`ViewModels/` 负责数据和交互逻辑，通过绑定互相联系。
